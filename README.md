# 100diary

全本地、零网络的极简日记记录工具。快速记录每日事件与伴随的状态反应——字段中性，不预设"感恩"或任何情绪方向，无打卡、无激励文案，数据完全属于你自己。

## 在线使用

<https://Poro789.github.io/100diary/>

> 在线版数据保存在**访问设备的浏览器**中，不经过任何服务器、不同步、不可被他人读取。如需长期可靠保存，建议下载本地版并定期导出 JSON 备份。

## 本地使用

1. 下载 [Release](../../releases) 中的 zip 包并解压（或直接使用本仓库）
2. 双击解压目录中的 `index.html` 用浏览器打开即可，无需安装、无需联网

兼容 Chrome / Edge / Firefox（桌面与移动端）。

> 需要单文件便携版？见 [v1.0.0 release](../../releases/tag/v1.0.0) 中的 `diary.html`。

## 功能

- **日记名称**：点击标题（或 ✎）即可重命名，随 JSON 一起导入导出；未设置时显示默认「日记」
- **Day X**：显示「第几个记录日」（只数有记录的日子，跳过的日子不计入，符合不强制打卡的定位）；录入区与历史列表均显示；派生字段，导入导出自动保持一致
- **多事件记录**：一次表单可填写多条事件（「＋ 添加事件」），一次保存全部追加到当天；也可继续逐次保存
- **情绪/身体选择**：每条事件独立、弹框点选（移动端为底部上滑面板，大触控目标），不手写
  - 情绪：Plutchik 情绪轮 8 种基本情绪（临床与情感计算中使用最广的离散情绪模型）+「平静」中性锚点——平静 / 喜悦 / 安心 / 期待 / 惊讶 / 悲伤 / 厌恶 / 愤怒 / 恐惧
  - 身体：基于唤醒维度与躯体标记研究的常见验证状态——放松 / 精力充沛 / 紧绷 / 疲惫 / 麻木
  - 选项带 emoji 图标（仅界面显示，JSON 存文字标签）；点击已选中的选项可取消，不选直接关闭弹框
- **历史**：按日期倒序，可展开/折叠，显示 Day X；日期可修改（重名自动合并）
- **编辑 / 删除**：单条事件或整天记录，均有确认提示
- **保存为图片**：任一天（仅单日）可导出为极简风竖版长图，含名称（若已设置）与 Day X；面向移动端（iOS 长按存相册，其他环境自动下载）
- **备份**：导出 `.json` 备份文件；换设备或浏览器时导入恢复（导入替换当前数据）
- **零依赖**：无框架、无构建步骤、无外部请求，整个应用仅 `index.html` + `css/style.css` + `js/app.js` 三个静态文件

## 数据存储与备份

- 数据仅存于浏览器 `localStorage`（键名 `diary.records.v1`），不经过任何网络
- 浏览器清除站点数据会丢失记录，请定期使用「导出 JSON」备份
- 备份文件结构与本地存储完全一致，可直接用于迁移

## 数据结构

面向未来扩展（如导出给 AI 分析）设计，程序可直接解析，无需迁移：

```json
{
  "name": "我的100天",
  "entries": [
    {
      "id": "20260826-001",
      "date": "2026-08-26",
      "items": [
        { "event": "解决了一个底层技术问题", "mood": "喜悦", "body": "精力充沛" },
        { "event": "工作系统更新导致烦躁到顶点", "mood": "愤怒", "body": "紧绷" },
        { "event": "只记了事件，没选状态" }
      ]
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `name` | 日记名称（选填；未设置时界面显示默认「日记」） |
| `id` | 唯一标识，`日期-当日序号` 格式，系统生成 |
| `date` | 记录日期（`YYYY-MM-DD`），系统生成、可编辑 |
| `items[].event` | 事件本身，客观描述（必填） |
| `items[].mood` | 情绪（选填，可选项之一；未选则省略该字段） |
| `items[].body` | 身体状态（选填，可选项之一；未选则省略该字段） |
| `items[].reaction` | 旧版自由文本（仅 v1.0 及以前的存量数据会有，编辑时原样保留） |

> **Day X**（第几个记录日）是派生字段：该日期在「有记录的日期」升序中的序号，不冗余存储，导入/导出后自动一致，无需迁移。

## 明确不做

- 情绪打分与趋势图表
- 社交 / 分享
- 任何情绪方向性文案或强制打卡激励

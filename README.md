# 100diary

全本地、零网络的极简日记记录工具。快速记录每日事件与伴随的状态反应——字段中性，不预设"感恩"或任何情绪方向，无打卡、无激励文案，数据完全属于你自己。

<https://Poro789.github.io/100diary/>

## 本地使用

1. 下载 [Release](../../releases) 中的 zip 包并解压（或直接使用本仓库）
2. 双击解压目录中的 `index.html` 用浏览器打开即可，无需安装、无需联网

兼容 Chrome / Edge / Firefox（桌面与移动端）。

> 需要单文件便携版？见 [v1.0.0 release](../../releases/tag/v1.0.0) 中的 `diary.html`。

## 功能

- **记录**：每条 = 事件（客观描述，必填）+ 状态/反应（选填，如情绪、身体感受）
- **追加**：同一天可多次追加，自动归入当日记录
- **历史**：按日期倒序，可展开/折叠；日期可修改（重名自动合并）
- **编辑 / 删除**：单条事件或整天记录，均有确认提示
- **备份**：导出 `.json` 备份文件；换设备或浏览器时导入恢复（导入替换当前数据）
- **零依赖**：无框架、无构建步骤、无外部请求，整个应用仅 `index.html` + `css/style.css` + `js/app.js` 三个静态文件

## 数据存储与备份

- 数据仅存于浏览器 `localStorage`（键名 `diary.records.v1`），不经过任何网络
- 浏览器清除站点数据会丢失记录，请定期使用「导出 JSON」备份
- 备份文件结构与本地存储完全一致，可直接用于迁移

## 数据结构

面向未来扩展（如导出给 AI 分析）设计，程序可直接解析，无需迁移：

```json
{
  "entries": [
    {
      "id": "20260826-001",
      "date": "2026-08-26",
      "items": [
        { "event": "解决了一个底层技术问题", "reaction": "很爽" },
        { "event": "工作系统更新导致烦躁到顶点", "reaction": "愤世嫉俗，但意识到这种状态能提升行动力" }
      ]
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识，`日期-当日序号` 格式，系统生成 |
| `date` | 记录日期（`YYYY-MM-DD`），系统生成、可编辑 |
| `items[].event` | 事件本身，客观描述（必填） |
| `items[].reaction` | 可选的状态/反应描述（可空字符串） |

## 明确不做

- 云同步、账号系统
- 情绪打分与趋势图表
- 社交 / 分享
- 任何情绪方向性文案或强制打卡激励
